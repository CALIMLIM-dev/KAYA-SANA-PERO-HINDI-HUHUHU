# ARCHITECTURE RULES (MANDATORY)

Never change the project's architecture without explicit approval.

## Reuse Existing Components

Before creating new ones, reuse existing:
- Controllers
- Services
- Models
- Components
- Helpers
- Middleware

## Pattern Consistency

Do not introduce new patterns when an existing pattern already solves the problem.

## Separation of Concerns

Keep responsibilities separated.

## File Management

Do not move files unless requested.
