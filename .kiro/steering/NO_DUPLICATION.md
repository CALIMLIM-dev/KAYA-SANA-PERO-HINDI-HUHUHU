# NO DUPLICATION (MANDATORY)

Never duplicate functionality.

## If Similar Functionality Already Exists:

- Extend it
- Reuse it
- Integrate with it

## Do Not Create Parallel Implementations

Creating duplicate code is not allowed.

## Detection During Implementation

If duplicate code is detected during implementation:
- STOP immediately
- Explain why duplication exists
- Do not continue
- Propose how to reuse existing code instead

## Examples of Duplication to Avoid:

- Creating a new model when one exists
- Creating a new endpoint when one exists
- Duplicating validation logic
- Duplicating UI components
- Duplicating service methods
- Creating parallel class hierarchies
